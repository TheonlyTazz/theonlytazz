## CurseForge projects

I publish Minecraft projects as a [CurseForge author](https://www.curseforge.com/members/theonlytazz/projects) with **10.8M+ downloads**.

| Project | Description |
| --- | --- |
| [BEER / Bookshelf Extended Enchanting Reach](https://www.curseforge.com/minecraft/mc-mods/bookshelf-extended-enchanting-reach) | Expands the range of bookshelf detection around enchanting tables. |
| [Deep Dark Dimensional Dungeons](https://www.curseforge.com/minecraft/mc-mods/deep-dark-dimensional-dungeons) | Adds basic dungeons inside the Ancient City portal experience. |
| [Colorful Allays](https://www.curseforge.com/minecraft/mc-mods/colorful-allays) | Adds vibrant color variants to Minecraft’s Allays. |
| [Deus Ex Machina: Reborn](https://www.curseforge.com/minecraft/mc-mods/deus-ex-machina-reborn) | Grants stacking resistance and strength against configured bosses after defeat. |
| [Busy Villagers](https://www.curseforge.com/minecraft/mc-mods/busy-villagers) | Lets villagers work overtime and through the night by removing their sleep schedule. |
